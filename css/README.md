## Sobre o projeto

O Sabor SL é um site que surgiu com a ideia de facilitar a vida das pessoas de Santa Luzia – PB na hora de encontrar lugares para comer ou pedir comida. Nossa proposta é reunir vários estabelecimentos em um só lugar, permitindo que os usuários encontrem informações sobre cardápios, localização, contato e outras informações importantes.

Além de ajudar as pessoas a encontrarem opções de alimentação, também queremos contribuir para que os vendedores locais divulguem seus estabelecimentos e produtos.

## Mudanças realizadas

No primeiro protótipo, apresentado no PDF, mostramos nossa ideia inicial para o site e planejamos algumas telas, como login, sugestões, pesquisa, perfil, configurações e informações dos vendedores.

Depois, começamos a transformar essa ideia em um site de verdade. Durante esse processo, fizemos algumas mudanças no visual e na organização das páginas para deixar tudo mais bonito, organizado e fácil de usar.

As principais mudanças foram:

- Criamos uma página inicial para apresentar o Sabor SL.
- Adicionamos uma barra lateral para facilitar a navegação pelo site.
- Organizamos os estabelecimentos em categorias, como lanches, restaurantes e sobremesas.
- Criamos cards para apresentar os estabelecimentos de forma mais organizada.
- Desenvolvemos páginas individuais para alguns estabelecimentos, com suas informações e cardápios.
- Criamos uma página de pesquisa para facilitar a procura por estabelecimentos e pratos.
- Adicionamos uma página de perfil e outra de configurações.
- Criamos uma página para apresentar o projeto e seus desenvolvedores.
- Adicionamos imagens para deixar o site mais atrativo.
- Organizamos melhor os arquivos HTML e CSS.
- Colocamos comentários no código para facilitar o entendimento.
- Fizemos ajustes no layout e na disposição dos elementos para melhorar a navegação.

Além dessas mudanças, buscamos fazer com que o site não ficasse apenas na parte visual. A proposta de evolução inclui recursos interativos, como pesquisa, filtros, favoritos e manipulação de formulários com JavaScript.

Algumas funcionalidades que imaginamos no início, como recuperação de senha e realização de pedidos on-line, ainda precisam ser desenvolvidas ou aprimoradas para funcionarem completamente.

## Tecnologias utilizadas

### HTML

Utilizamos HTML para criar a estrutura das páginas, organizando os textos, as imagens, os botões, os links e as informações dos estabelecimentos.

### CSS

Utilizamos CSS para cuidar da aparência do site, escolhendo as cores, os tamanhos, os espaçamentos e a organização dos elementos. Com ele, conseguimos deixar as páginas mais bonitas e manter um visual organizado.

### JavaScript

O JavaScript é importante para tornar o site mais interativo, permitindo que algumas funcionalidades respondam às ações dos usuários.

Na evolução do Sabor SL, buscamos utilizar esse recurso para trabalhar com variáveis, constantes, operadores e formulários, além de desenvolver funcionalidades relacionadas à pesquisa, aos filtros e aos favoritos.

A intenção é melhorar o funcionamento do site e permitir que ele ofereça mais recursos além da navegação entre as páginas.

## Como usar o sistema

Para acessar o site, primeiro é necessário extrair a pasta do projeto.

Depois, basta seguir estes passos:

1. Abrir a pasta do projeto.
2. Localizar o arquivo `index.html`.
3. Abrir o arquivo no navegador.
4. Na página inicial, clicar em **Entrar**, caso essa opção esteja disponível.
5. Utilizar a barra lateral para acessar as outras páginas.

### Navegação

Na barra lateral, encontramos algumas opções:

- **Início:** volta para a página principal.
- **Buscar:** permite procurar estabelecimentos ou pratos.
- **Perfil:** apresenta a área de informações do usuário.
- **Configurações:** mostra as opções disponíveis do sistema.

Também podemos acessar as categorias de alimentação e escolher um estabelecimento para conhecer melhor suas opções.

### Como visualizar um estabelecimento

1. Entrar em uma das categorias.
2. Escolher o estabelecimento desejado.
3. Clicar no card correspondente.
4. Consultar as informações e o cardápio disponível.

## Objetivo do projeto

Nosso objetivo com o Sabor SL é facilitar a busca por lugares para comer ou pedir comida em Santa Luzia – PB, reunindo informações de diferentes estabelecimentos em um único site.

Também queremos ajudar os vendedores locais a divulgarem seus produtos e alcançarem mais pessoas por meio da internet.

Durante o desenvolvimento, tivemos a oportunidade de colocar em prática os conhecimentos adquiridos na disciplina de Desenvolvimento de Aplicações Web I, trabalhando com HTML, CSS e a proposta de utilização do JavaScript para acrescentar funcionalidades ao projeto.
